# Windows x64 自建桌面版与手机连接

此安装包由 fork 的 GitHub Actions 在 Windows x64 构建。打开 Desktop 工作区后，使用“文件 → 复制手机访问链接”，在同一局域网的手机浏览器中打开。手机接入该窗口已有 Host，可选择并继续同一工作区的任务。链接带随机令牌，窗口或工作区关闭后失效。

本次验证包含源码类型、Lint、隐私检查、Web 与 Desktop 构建，以及安装包内 Web 页面资源检查。尚未在真实手机和 Windows 安装后的完整交互中验证，故标记为预发布。

自建版禁用已识别的 ZCode 数仓、ARMS、OTLP、官方 Provider 刷新、官方配置读取、自动更新与强制升级入口。用户配置的模型 API 和工具仍可联网。需要强制限定所有出站目的地时，应额外配置系统防火墙白名单。
